Trust & Safety: kiến trúc (v2)

Safety là module dùng chung trong core-api, giữ Report và Block append-only ở PostgreSQL.

Bản v2 vẽ lại sơ đồ KIẾN TRÚC của bản đầu từ đúng dữ liệu catalog đã xuất bản (thành phần, cạnh, module, thực thể, dịch vụ ngoài); không có luồng xử lý, không kiểm lại với code hôm nay. Phần đã đổi cho bài toán 10 triệu đồng thời nằm ở trang kiến trúc 10M.

Điểm quan trọng

Safety là module dùng chung trong core-api, giữ Report và Block append-only ở PostgreSQL. Trạng thái block được xác định từ action mới nhất; report-user và trust penalty commit cùng transaction.

Lưu ý

Mỗi module gọi lại guard tại thời điểm hành động, không chỉ lúc mở màn. Report-user, report-video và admin ban có semantics riêng; Gateway và Redis không quyết định cho phép tương tác.

Quan hệ giữa module

#Từ → đếnLàm gìĐiều kiện
1Safety → UseradjustTrustScore cùng Report transaction
2Matching / Discovery → SafetycanPair / hidden-set đúng thời điểm
3Friend / Feed → SafetyBlock guard khi gửi/đọc/tương tác
4ShortVideo / Admin → SafetyVideo report / report inspection
5ShortVideo / Admin → User chỉ liệt kê, không vẽ mũi tênAdmin ban/unban qua User API
