Mini Game: code theo từng endpoint

Mỗi endpoint là một file, đọc từ trên xuống theo thứ tự chạy: code controller, hàm nó gọi được chép ngay tại dòng gọi, ngang cấp (chỉ thân hàm; chỉ khối { } của code mới thụt vào), cứ thế xuống service, Postgres, Redis, worker. Mỗi khối có dòng tiêu đề [TẦNG] tô màu (CONTROLLER, SERVICE, WORKER, POSTGRES, REDIS, KAFKA, BULLMQ, EXTERNAL, GATEWAY), có đánh số Step, và một constructor gom hạ tầng trực tiếp và phần khởi tạo liên quan ở đầu trang. Có cấu hình và logic middleware, guard, interceptor, pipe và exception filter thực sự áp dụng. Chỉ lược DTO, Metrics và implementation của thư viện ngoài. Comment chỉ trả lời "vì sao" ở chỗ logic khó.
