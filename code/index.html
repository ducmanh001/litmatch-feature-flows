Các luồng khó của Litmatch: code kèm lời giải thích

Chỉ chọn luồng có nhiều nghiệp vụ hoặc cơ chế kỹ thuật (Redis, transaction DB, idempotency, webhook, worker nền); bỏ CRUD cơ bản. Mỗi chức năng là một trang: code thật đọc từ trên xuống theo thứ tự chạy, hàm được gọi chép ngay tại dòng gọi, ngang cấp (chỉ khối { } mới thụt vào), có đánh số Step và nhãn tầng tô màu; comment chỉ trả lời "vì sao" ở chỗ logic khó. Mở trang để xem vai trò từng tầng, từng bảng, từng module liên quan.
