Avatar tùy chỉnh: code theo từng endpoint

Mỗi endpoint là một file: client → controller → service → DB, chỉ giữ luồng xử lý chính. Không chép DTO, interface, schema và phần dùng chung (middleware, guard, interceptor, pipe toàn cục, exception filter).
